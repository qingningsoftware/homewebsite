# 青柠官网重建实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按设计稿在 `src/` 用 Astro 重建青柠官网：暗色终端科技风纯静态站（13 个页面）+ 留言墙，GEO 全套，交付构建产物与部署文档。

**Architecture:** Astro 静态生成（零框架 JS），内容 = 内容集合（products Markdown）+ 数据文件（services/wall-messages/certificates JSON，公司侧可编辑后重建）；交互（boot/伪命令行/打字机/散布墙动效/本地留言）全部为直出 HTML 之上的渐进增强；公共样式为 CSS 自定义属性设计系统。

**Tech Stack:** Astro 5（静态输出）、TypeScript、Vitest + jsdom（lib 单测）、@astrojs/sitemap；无任何运行时后端。

**Spec:** `doc/2026-11-20-青柠软件官网-设计稿.md`（已批准，含 §12 留言墙增补；本计划 argues from the spec，文案细节不在计划中复述）。

## Global Constraints（每个任务默认携带）

- 全部页面文案、注释、提交信息用中文。
- 正文必须服务端直出 HTML，禁止依赖客户端 JS 渲染内容；JS 仅为动效/本机留言的渐进增强。
- 色板 token（global.css 变量，逐字采用）：背景 `#0A0A0A`/`#111113`；面板 `#161618`；边框 `#2A2A2E`；青柠 `#A3E635`（hover `#BEF264`）；暗绿 `#65A30D`；正文 `#E5E7EB`；次要 `#8B8B92`；成功 `#4ADE80`；警告 `#FBBF24`；错误 `#F87171`。
- 字体：等宽栈 `ui-monospace, 'JetBrains Mono', 'Fira Code', Consolas, monospace`（标题/代码感元素）；中文正文 `-apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif`。不加载 webfont。
- 动效统一 CSS + IntersectionObserver，进场触发一次不重复；`prefers-reduced-motion` 下全部动效直接显示为静态。
- 数字口径：定性描述；硬事实仅「2016 年成立 / 软著 10 项 / 6 套解决方案 / 覆盖全国 2800+ 院校」。
- 遗留信息禁入：whatsapp、模板作者个人 GitHub/Twitter、COMSATS、`www.baidu.com/a.pdf`；`sameAs` 只写 Gitee。
- 图片全部本地化（`src/assets/`），不热链任何旧域名 URL。
- canonical 基准 `https://www.qingningsoft.cn`（astro.config `site`）。
- 留言墙：预置数据 `src/data/wall-messages.json`；localStorage key `qn-wall-messages`；本机留言上限 30 条；输入上限 200 字；散布种子固定 `20261121`。
- 提交信息格式：`feat|fix|chore: 中文描述`，末尾加 `Co-Authored-By: Claude Code <noreply@anthropic.com>`（下文各任务「提交」步骤均同，不再重复）。

## Review Focus（人用这站最可能踩的坑；每条已落到拥有该代码的任务里）

1. **AI/搜索引擎抓不到正文**（重蹈旧站覆辙）→ 预期：dist 每页 HTML 文件内直接含正文文案。任务 13 的 `scripts/check-dist.mjs` 对全部 dist 页面 grep 必含文案；各页任务验证步骤也抽查。
2. **遗留个人信息混进构建产物** → 预期：dist 全量 HTML 无禁入词。任务 3 的守卫单测管数据文件，任务 13 扩展到 dist。
3. **`prefers-reduced-motion` 下动效不停、内容不可见** → 预期：全部动效类有 reduced-motion 覆盖，boot 直接不出、墙静态全显。任务 4/6/7 验证步骤逐一核对 CSS 块。
4. **本机留言边界**（localStorage 损坏、超 30 条、超 200 字、无浏览器环境 SSR 报错）→ 预期：损坏重置、超限明确拒绝、SSR 安全。任务 6 单测覆盖。
5. **100 条留言时散布墙重叠失控/画布不增长** → 预期：确定性布局、角度 ≤±6°、允许 ≤12px 轻叠、总高随条数增长。任务 6 scatter 单测覆盖。
